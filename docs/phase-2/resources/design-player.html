Rules

  • Land: no selected track. Bar not mounted. No autoplay.
  • Click a card = user gesture = start that stream. Bar appears. Card gets ON.
  • One <audio>. Source = that row’s stream_blob_url. Native seek/play/pause in the bar (or styled on top of the same element).
  • Click another card: switch source, play from 0. Old ON clears.
  • Click the ON card again: pause / resume. Do not restart.
  • Bar play/pause matches the card. INSTALL opens the modal (section 3). Does not pause unless you want — default: keep playing under the modal.
  • Stream 404 / fail: bar stays, title stays, transport dead, one mono line STREAM_UNAVAILABLE.
  • No volume slider in phase-2. Browser default is enough.
