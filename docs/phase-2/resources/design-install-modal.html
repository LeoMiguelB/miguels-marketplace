Rules

  • INSTALL opens modal. Backdrop dims grid. Bar stays up and keeps playing. Esc / ✕ / backdrop click closes. Close dumps the form.
  • Order in modal: title INSTALL · {TITLE} → T&C scroll box → contact fields → checkbox → DOWNLOAD.
  • T&C is full global copy (not per-track). Scroll to last line → checkbox enables. No scroll cheat (no jump-to-end control).
  • Checkbox off or email empty/invalid → DOWNLOAD dead (looks disabled, no click).
  • Fields: email required. Optional: name, role (producer / artist / other), instagram, x.
  • Phase-2 Download click: do not fetch a file. Do not send download_blob_url to the client. Show one mono line in the modal: DOWNLOAD_UNAVAILABLE. Stay open.
  • No new routes. Terms are not a page.
