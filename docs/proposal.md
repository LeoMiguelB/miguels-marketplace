For a long time now i've been using third party services to sell my music products. This includes kits that contain premade melodies, drumkits, and instrumentals that folks can buy. All of these i've sold exclusively on beatstars. In this day and age I think with the available resources anyone should be able to own their business end to end. So I think for me, it's about time I create my own store.

I want to start off simple and build up from there. We'll build a fullstack application - traditional frontend, backend architecture. 

So here's the core features that I want:

1. I should be able view/create/edit/delete audio files that show up in the frontend from the backend
2. playable streams for end users to listen to
3. users shall be able to install the files they want

The main goal for this website from my perspective is that users entering should be able to browse different playable streams, and if they like one they should be able to install. Now here's how I actually benefit from it. For all audio files, we have terms and conditions that states that if one decides to use those audio files for profit use then X% must be given to me.

As the sole owner of the website I think it'd be alot easier if we set these constraints:

1. for now let's build a simple CLI to upload/create/edit files, let's only let people view on the frontend
2. there shouldn't be need for auth, frontend should be accessible to anybody

Moreover, my budget, ideally is to be 0$ or near that. I want minimal cost as I don't really upload very frequently, and I don't have a big catalogue.
